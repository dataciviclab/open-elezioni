# Datasets

Questa cartella ospiterà i dataset principali (uno per directory, ognuna con
`dataset.yml`). Sono in migrazione da `open-politica`:

- `elezioni-politiche`, `elezioni-europee`, `elezioni-regionali`,
  `elezioni-comunali`, `elezioni-referendum`
- `dait-amministratori-locali`, `dait-amministratori-storico`

Il codice condiviso per le fonti ZIP/CSV/XLSX di Eligendo vive in
`datasets/_shared/eligendo.py`.

Fino alla migrazione, i dataset restano in `open-politica`.
