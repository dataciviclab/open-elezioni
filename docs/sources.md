# Fonti ufficiali

## Eligendo — risultati elettorali

- ente: Ministero dell'Interno — DAIT, Direzione Centrale per i Servizi Elettorali
- pagina: https://elezionistorico.interno.gov.it/eligendo/opendata.php
- download: https://dait.interno.gov.it/documenti/opendata/<tipo>/...
- licenza: CC BY 4.0
- formato: ZIP con CSV/TXT/XLSX (delimitatore `;`, encoding misto)

## DAIT — Anagrafe degli amministratori locali e regionali

- pagina: https://dait.interno.gov.it/elezioni/open-data/amministratori-locali-e-regionali-in-carica
- formato: CSV `;` (snapshot corrente + storico al 31/12)

## SUT — Sistema Unico Territoriale

- pagina: https://dait.interno.gov.it/territorio-e-autonomie-locali/sut/
- open data: https://dait.interno.gov.it/territorio-e-autonomie-locali/indice-sut/open-data/
- licenza: CC BY 4.0
- file: comuni (codici/censimento/contatti), sezioni elettorali, collegi
  Camera/Senato, unioni di comuni, fusioni, prefetture

## Fuori perimetro

- **Finanza locale** (`finanzalocale.interno.gov.it`): non è open data in bulk,
  è un sistema di interrogazione HTML per singolo ente. Esclusa da questo repo.
- **Servizi demografici / ANPR**: fonte separata, non coperta qui.
